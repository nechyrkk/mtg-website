# МТГ — статический сайт

Откройте index.html в браузере. Вёрстка состоит из обычных HTML, CSS и JavaScript; сборка, сервер и зависимости для неё не нужны. При автоматической проверке использовался локальный HTTP-предпросмотр; доступ к file:// в инструменте браузера ограничен.

## Страницы

Всего 56 HTML-страниц:

- index.html — главная.
- catalog.html — 28 919 позиций номенклатуры, поиск по названию и артикулу, категории и производитель, сброс, параметры в URL. Все товары показываются на одной странице с пагинацией по 12 карточек; отдельные страницы товаров не создаются.
- about.html — поставки, комплексное снабжение, склад, доставка и гарантия на продукцию.
- equipment.html — 25 видов техники с иллюстрациями и ссылками на отдельные страницы equipment-*.html.
- certificates.html — 9 сертификатов с увеличением.
- services.html — направления диагностики, ремонта и обслуживания, заявка и переход на сайт НТЦ СЕРВИС. Опция «Подробнее» в карточках удалена; семь ранее существовавших страниц service-*.html сохранены по старым адресам.
- brands.html и 6 страниц brand-*.html — подбор по маркам техники.
- delivery-*.html — 11 направлений доставки, открываются из географии поставок на странице компании.

Все страницы доступны по внутренним ссылкам. Тематические тексты подготовлены для согласования; это не полный перенос содержимого старого сайта. Старые URL и тексты будут сопоставлены после получения выгрузки.

## Каталог

Данные — assets/js/catalog-data.js. Внесены позиции из двух предоставленных таблиц, без вымышленных цен, остатков и фотографий. Работают комбинированный поиск, фильтры и пагинация. Отчёт сверки — catalog-import-report.json, повторный импорт — scripts/import-catalog.py.

Производитель детали и марка техники — разные признаки. В исходниках они не всегда разделены, поэтому фильтр подписан «Производитель / марка». Обозначения из источников сохранены; наличие товара уточняется у менеджера.

Схема данных и описание механизма — CATALOG-DATA.md. В WordPress фильтрация большого каталога переносится на сервер.

Проверка чистой логики: node --test checks/*.test.cjs. Примеры из теста не загружаются на сайт.

## Исходники

- assets/css/style.css — базовая вёрстка.
- assets/css/pages.css — внутренние страницы.
- assets/css/illustrated-pages.css — иллюстрированные заголовки и карточки техники.
- assets/css/features.css — каталог, услуги и тематические страницы.
- assets/css/revisions.css — обновлённый логотип, мобильная вёрстка и доставка.
- assets/js/main.js — меню, форма и сертификаты.
- assets/js/catalog-filter.js — логика поиска и фильтров.
- assets/js/catalog.js — интерфейс каталога.
- assets/images/ — иллюстрации, сертификаты и логотипы.
- assets/images/categories/ — шесть собственных векторных значков категорий.

Тексты компании и реквизиты взяты из присланных PDF и последующего скриншота с географией поставок и гарантией. Тексты повторно сверены 27.10.2026 с полным текстовым файлом правок: восстановлены условия работы, раздел сервиса и окончание страницы компании, полные формулировки услуг и производителей. Четыре сертификата заменены присланными обновлениями. На главной и в карточках техники используются новые иллюстрации, созданные встроенным ImageGen без исходных фотографий; это иллюстративные сцены, а не документальные фотографии конкретных моделей. Пути, промпты и сведения об изображениях — assets/images/original/README.md и prompts.json.

Форма только проверяет имя и телефон. Данные не сохраняются и не отправляются. Кнопка запроса цены передаёт название и артикул в форму. WordPress, админка и отправка заявок — следующий этап; номенклатура уже загружена в статический каталог.

## Сохранение старого содержимого и URL

Реестр 417 адресов и черновик сопоставления находятся в соседней папке migration. Это неполный список сайта, а не окончательный план редиректов. Новые локальные имена HTML пока не утверждены как публичные адреса WordPress. На хостинге ничего не менялось. После выгрузки проверяем тексты, товары, картинки и адреса; по возможности сохраняем старые URL, иначе готовим адресные постоянные перенаправления на соответствующие страницы.

Папка site с первой реализацией к этому варианту не относится.

## Публикация

Сайт подготовлен для GitHub Pages: публикация из корня ветки main. Файл .nojekyll отключает обработку Jekyll и сохраняет обычные HTML, CSS и JavaScript. Внешняя тема не требуется. Все ссылки и пути к ресурсам относительные, поэтому сайт работает и в подкаталоге репозитория. Папка preview содержит локальные снимки экрана и исключена из Git.

Для семи направлений сервиса подготовлены разные иллюстрации встроенным ImageGen. Они используются в карточках услуг и заголовках соответствующих страниц. Это иллюстративные сцены, не документальные фотографии компании. Файлы и промпты — assets/images/services/README.md.
