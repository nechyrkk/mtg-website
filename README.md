# МТГ — статический сайт

Откройте index.html в браузере. Вёрстка состоит из обычных HTML, CSS и JavaScript; сборка, сервер и зависимости для неё не нужны. При автоматической проверке использовался локальный HTTP-предпросмотр; доступ к file:// в инструменте браузера ограничен.

## Страницы

Всего 45 HTML-страниц:

- index.html — главная.
- catalog.html — поиск по названию и артикулу, категории и производитель, сброс, параметры в URL; пока 18 подписанных заглушек и ноль реальных товаров.
- about.html — текст компании и перечень работ из письма.
- equipment.html — 25 видов техники с иллюстрациями и ссылками на отдельные страницы equipment-*.html.
- certificates.html — 9 сертификатов с увеличением.
- services.html и 7 страниц service-*.html — направления диагностики, ремонта и обслуживания.
- brands.html и 6 страниц brand-*.html — подбор по маркам техники.

Все страницы доступны по внутренним ссылкам. Тематические тексты подготовлены для согласования; это не полный перенос содержимого старого сайта. Старые URL и тексты будут сопоставлены после получения выгрузки.

## Каталог

Данные — assets/js/catalog-data.js. Сейчас products пуст. Не заполненные реальные данные не имитируются случайными ценами, артикулами и остатками. При выборе категории видны её заглушки. Поиск, артикул и производитель показывают состояние наполнения, пока нет базы. После внесения данных работают комбинированный поиск и пагинация.

Производитель детали и марка техники — разные признаки. Список производителей деталей взят со старого сайта; наличие товаров этих производителей не утверждается.

Схема данных и описание механизма — CATALOG-DATA.md. В WordPress фильтрация большого каталога переносится на сервер.

Проверка чистой логики: node --test checks/catalog-filter.test.cjs. Примеры из теста не загружаются на сайт.

## Исходники

- assets/css/style.css — базовая вёрстка.
- assets/css/pages.css — внутренние страницы.
- assets/css/illustrated-pages.css — иллюстрированные заголовки и карточки техники.
- assets/css/features.css — каталог, услуги и тематические страницы.
- assets/js/main.js — меню, форма и сертификаты.
- assets/js/catalog-filter.js — логика поиска и фильтров.
- assets/js/catalog.js — интерфейс каталога.
- assets/images/ — присланные материалы и заглушки.

Тексты компании и реквизиты взяты из присланных PDF. Несколько строк PDF «О компании» обрезаны справа; окончания восстановлены по смыслу и требуют сверки с исходным письмом. Изображения видов техники извлечены из присланного макета и улучшены встроенным ImageGen. Версии шириной 640 и 1440 пикселей находятся в assets/images/equipment-hd; оригиналы сохранены. Это AI-реконструкция, а не документальные фотографии конкретных моделей.

Форма только проверяет имя и телефон. Данные не сохраняются и не отправляются. WordPress, админка, товарная база и отправка заявок — следующий этап.

## Сохранение старого содержимого и URL

Реестр 417 адресов и черновик сопоставления находятся в соседней папке migration. Это неполный список сайта, а не окончательный план редиректов. Новые локальные имена HTML пока не утверждены как публичные адреса WordPress. На хостинге ничего не менялось. После выгрузки проверяем тексты, товары, картинки и адреса; по возможности сохраняем старые URL, иначе готовим адресные постоянные перенаправления на соответствующие страницы.

Папка site с первой реализацией к этому варианту не относится.

## Публикация

Сайт подготовлен для GitHub Pages: публикация из корня ветки main. Файл .nojekyll отключает обработку Jekyll и сохраняет обычные HTML, CSS и JavaScript. Внешняя тема не требуется. Все ссылки и пути к ресурсам относительные, поэтому сайт работает и в подкаталоге репозитория. Папка preview содержит локальные снимки экрана и исключена из Git.

Для семи направлений сервиса подготовлены разные иллюстрации встроенным ImageGen. Они используются в карточках услуг и заголовках соответствующих страниц. Это иллюстративные сцены, не документальные фотографии компании. Файлы и промпты — assets/images/services/README.md.
