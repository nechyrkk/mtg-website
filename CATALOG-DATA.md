# Каталог номенклатуры

Одна страница catalog.html содержит поиск, фильтры и пагинацию по 12 позиций. Отдельные HTML-страницы товаров не создаются. Параметры URL сохраняют состояние одного каталога.

В каталоге 28 919 позиций: 28 897 из полной XLS-выгрузки и 22 дополнительные из XLSX. 1 354 строки второй таблицы совпали по артикулу и обозначению производителя с уже импортированными позициями и повторно не добавлены. Десять пустых строк и строк справочника не стали товарами. Подробный отчёт — catalog-import-report.json.

Артикулы сохраняются текстом, без добавления .0 к числовым значениям. Пустые значения и нулевой артикул оставлены незаполненными. Исходные коды полной выгрузки служат устойчивыми ID. Производители и марки приведены по исходным таблицам, включая обозначения стран; это не утверждение о производителе каждой детали. Похожие обозначения и варианты написания не объединялись автоматически.

Категории определены осторожно по словам в названиях. Неоднозначные позиции находятся в категории «Другие запчасти и материалы». Для полноценной товарной классификации потребуется проверка владельцем базы. Поиск по названию, артикулу и производителю доступен для всех позиций независимо от категории.

Цены, остатки, фотографии и характеристики не предоставлены. Они не выдумываются. Кнопка «Запросить цену» открывает существующую форму с названием и артикулом. Форма остаётся локальным предпросмотром, пока не подключён приём заявок.

## Повторный импорт

Из корня репозитория, с Python и пакетами xlrd, openpyxl:

```powershell
python scripts/import-catalog.py "путь/полная-номенклатура.xls" "путь/номенклатура-для-сайта.xlsx"
```

Скрипт не изменяет Excel-файлы. Он перезаписывает assets/js/catalog-data.js и отчёт импорта. Исходные таблицы и письма не включены в публичный репозиторий.

Сайт работает при открытии HTML двойным щелчком. Файл данных загружается один раз; DOM содержит только текущие 12 карточек. На этапе перехода на CMS базу можно перенести в серверный каталог, сохранив этот интерфейс.

## Проверка

```powershell
node --test checks/*.test.cjs
node --check assets/js/catalog-data.js
node --check assets/js/catalog.js
```

В заголовке карточки повтор полного артикула скрывается; исходное название в базе сохранено. Артикул остаётся отдельным полем, участвует в поиске и один раз передаётся в заявку. Короткие коды и совпадения внутри более длинного обозначения не удаляются, чтобы сохранить модели и размеры. Для всех позиций без индивидуального фото используется единая сгенерированная фотозаглушка с подписью «Иллюстрация».
