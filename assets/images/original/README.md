# Новые иллюстрации

Новый набор для главной страницы, заголовков внутренних страниц и 25 видов спецтехники. Создан встроенным ImageGen по текстовым запросам, без исходных фотографий и без их реконструкции. Это иллюстрации, а не документальные фотографии техники, объектов или сотрудников компании.

- `hero-original.webp` — главная и общие заголовки.
- `service-original.webp` — сервисный баннер и заголовок услуг.
- `catalog-placeholder.webp` — общая фотозаглушка с ассортиментом деталей для товаров без фото. Точный запрос — `catalog-placeholder-prompt.json`; создана встроенным ImageGen без фотографий-источников.
- `equipment/equipment-NN.webp` — 25 изображений для страниц видов техники, ширина до 1440 px.
- `equipment/equipment-NN-card.webp` — версии для карточек, ширина 640 px.
- `prompts.json` — полный набор текстовых запросов и пути к результатам. Режим: встроенный `image_gen`, без CLI/API-ключа.

Прежние фотографии и версии, реконструированные по ним, исключены из текущих ресурсов сайта. Существующие семь иллюстраций услуг в соседней папке `services/` также созданы отдельно по текстовым запросам. Логотипы брендов и предоставленные сертификаты сохранены как отдельные материалы.
