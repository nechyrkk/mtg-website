# Иллюстрации видов спецтехники

25 изображений улучшены встроенным ImageGen по исходникам `../equipment-01.webp` — `../equipment-25.webp`. Оригиналы сохранены.

Это AI-реконструкция деталей небольших исходных иллюстраций, а не точное восстановление оригинальных фотографий или подтверждение модели техники.

- `equipment-NN-card.webp`: 640 px по ширине для карточек.
- `equipment-NN.webp`: 1440 px по ширине для подробных страниц и экранов высокой плотности.
- `assets.json`: фактические размеры.
- `prompts.json`: полный набор использованных запросов.

Изображения подключены через srcset/sizes в equipment.html и 25 страницах equipment-*.html.
