# Иллюстрации услуг

Семь отдельных иллюстраций для диагностики, выездного ремонта, гидравлики, КПП, электрики, обслуживания и восстановления узлов. Созданы встроенным ImageGen; это общие иллюстративные сцены, а не фотографии сотрудников или объектов компании.

Каждое изображение используется в своей карточке раздела «Услуги» и на соответствующей странице. Исходные сгенерированные PNG сохранены отдельно; для сайта подготовлены оптимизированные WebP.

Точные промпты записаны в [prompts.json](prompts.json). При получении фотографий заказчика WebP можно заменить, сохранив имена файлов.

- [diagnostics.webp](diagnostics.webp) — диагностическое оборудование.
- [field-repair.webp](field-repair.webp) — выездной ремонт.
- [hydraulics.webp](hydraulics.webp) — гидроцилиндр и уплотнения.
- [transmission.webp](transmission.webp) — открытая коробка передач.
- [electrics.webp](electrics.webp) — проверка электрических цепей.
- [maintenance.webp](maintenance.webp) — обслуживание и фильтры.
- [restoration.webp](restoration.webp) — восстановление ковша сваркой.
